To use in a formula, mix the accord first, then dose 5-30% of it
into your finished perfume concentrate.

═══════════════════════════════════════════════════════════════════════════════
  HOW TO USE THESE ACCORDS
═══════════════════════════════════════════════════════════════════════════════

1. WEIGH the accord as a 100% concentrate (e.g., 5g total)
2. MIX thoroughly with glass rod
3. MACERATE 24-72 hours minimum (1 week for iris, vetiver)
4. USE as a single "material" in your formula at the recommended %

EXAMPLE: Building a "Terre d'Hermès inspired" EDP at 15% in 30mL

  Formula (100% concentrate = 3.82g):
    Vetiver Earthy Base accord     50%  = 1.91g
    Amber Radiant Base accord      15%  = 0.57g
    Peppery-Spice Base accord      10%  = 0.38g
    Clean Musk Base accord         10%  = 0.38g
    Bergamot FCF                    8%  = 0.31g
    D-Limonene                      5%  = 0.19g
    Grapefruit FCF                  2%  = 0.08g
                                  ─────
                                  100%  = 3.82g concentrate

  Then add: 21.6g ethanol → 25.42g total = ~30mL at ~15%
