═══════════════════════════════════════════════════════════════════════════════
  ARCHITECTURE OVERVIEW — THE 7 LAYERS
═══════════════════════════════════════════════════════════════════════════════

Every well-structured perfume needs these functional layers.
Not every layer needs multiple materials — some use just one.

  LAYER 1: DIFFUSION CORE        (2-5%)    — What throws off the skin
  LAYER 2: TOP / OPENING         (8-15%)   — First 30 minutes
  LAYER 3: HEART ACCORD          (25-40%)  — The main character
  LAYER 4: WOODY / AMBER SPINE   (15-25%)  — Structure and warmth
  LAYER 5: MUSK BASE             (5-15%)   — Skin scent, tenacity
  LAYER 6: SWEET MODIFIERS       (1-5%)    — Sweetness, gourmand touches
  LAYER 7: TRACE / EFFECT        (0.1-1%)  — Subliminal character shifts
