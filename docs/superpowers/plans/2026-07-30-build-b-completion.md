**Goal:** Finish Build B as one fail-closed scientific authority system in

## Method

Every phase uses the same gate:

1. Read the exact master-prompt phase and inspect current repository state.
2. Freeze Sol's architecture, interfaces, negative cases, and evidence gate.
3. Run fresh exact-project `deepseek_check`.
4. If `READY`, assign one bounded DeepLuna Fast task with `FLASH`,
   `NO_LUNA`, one attempt, allowlisted paths, and no architecture authority.
5. Write RED tests before implementation.
6. Implement one bounded slice at a time and commit exact paths only.
7. Run focused tests, lint, typing, migration/round-trip checks, and broader
   compatibility tests proportional to the shared contract.
8. Run a second fresh readiness check and bounded independent Fast validation.
9. Sol verifies or rejects every worker claim against code and executable
   evidence, writes the phase report, and passes or blocks the exit gate.

No later phase starts until the preceding gate passes.

## B2 — Observation-first properties

- Add exact identity scope and immutable typed property observations.
- Preserve numeric, categorical, interval, distribution, and censored values.
- Add visible conflict sets and explicit candidate decisions.
- Add versioned selected assertions addressed by ID and policy, never “latest.”
- Freeze every legacy `LabMaterialProperty` as `LEGACY_HEURISTIC`; migrate no
  legacy scalar into a canonical observation.
- Connect B1 extraction IDs to B2 observations through validated service
  commands without adding a parallel source store.

**Gate:** every migrated runtime property is observation-traceable or visibly
legacy heuristic; `not detected` is never zero; unresolved material conflicts
withhold authority.

## B3 — Contextual thresholds and OAV

- Specialize B2 observations with threshold endpoint, route, matrix,
  concentration basis, apparatus, psychophysics, and population context.
- Introduce explicit unit/convention conversion prerequisites.
- Compute OAV only for compatible concentration/threshold contexts.
- Return stable mismatch reason codes and enforce strict science mode.
- Migrate existing ODT records with their actual legacy status only.

**Gate:** context mismatches withhold OAV, and OAV alone cannot authorize
intensity, contribution, similarity, longevity, sillage, or release claims.

## B4 — Knowledge-rule compiler

- Inventory the rule corpus and classify exact identities, explicit groups,
  prose, contradictions, duplicates, cycles, and orphan references.
- Create a versioned canonical rule schema and explicit relation vocabulary.
- Compile only resolved, scoped rules; separate blocking, advisory,
  explanatory, speculative, invalid, and superseded records.
- Require controlled observation evidence before numerical interaction-model
  promotion.

**Gate:** invalid exact rules cannot increase; generic prose cannot mutate a
formula; every runtime recommendation exposes rule status and scope.
