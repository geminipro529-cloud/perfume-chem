## How to Request a Formula

### Simple way:
> "Make me a rose-oud at 15% concentration, 30mL bottle"

### Precise way (recommended):
> "Rose Classic 25%, Oud Dark 15%, Saffron Precious 10%, Amber Radiant 15%, Sandalwood Creamy 15%, Musk Intimate 20% — 10mL concentrate, then optimize for longevity"

### What I'll do:
1. Convert your % breakdown into exact µL/mL amounts for the batch size
2. List the raw materials needed from inventory
3. Calculate concentrate % and ethanol needed
4. **(If you say "optimize")** Run through the 10-axis scoring pipeline and suggest material swaps to improve weak axes

### Rules:
- All bases must sum to **100%** (I'll tell you if they don't)
- You can add individual raw materials alongside bases (e.g., "+ 5% Bergamot FCF")
- Default batch size is **10mL concentrate** unless you specify otherwise
- Default concentration is **15% EDP** unless you specify otherwise
