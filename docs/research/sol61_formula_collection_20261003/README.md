Independent Python Decimal reconstruction checked all three lead sums, every row's product/stock/carrier arithmetic, all **15 specified new candidate targets**, final-mass and small-sample totals, the exact lavender ratio and separate Ambrox weights. Current inventory, the three parents and the twelve original Sol61 source files were checked by SHA-256.

The legacy pre-mix/headspace gate was not run or passed: parent active masses and applicable gas-release evidence were not fabricated. No full repository test suite, sensory work, physical compounding, stability study or safety assessment was performed. Repository-wide `git diff --check` returned no whitespace-error exit but reported permission warnings on pre-existing verification artifacts; the new files also receive a focused whitespace check.

The honest next step is a small coded blotter test of the lead and one relevant alternative—not a claim of a universal winner or an automatic change to an existing bottle.
