# Floral and aromatic architecture v3: reviewed implementation plan

Date: 2026-10-07. Scope: advisory design software and its diagnostics. No formula,
inventory, purchase, compounding, empirical capability or release change.

## Frozen implementation scope

Append 22 bounded comparisons to the 22 v2 mappings, preserving v1 and v2 bytes,
ordered mappings and explicitly selectable historical protocols. Every request
keeps its unchanged structural control and at most two unordered alternatives.

Within v3 only, a matching qualified subtype precedes its broader umbrella by
number of required match groups (stable manifest order breaks ties). This is
request specificity, not scientific superiority. V1/v2 keep their original order.

New cards: ROSE_LEMONY, ROSE_HONEY, ROSE_METALLIC, ROSE_DARK_PATCH, JAS_GRANDIFLORUM, JAS_LEATHER, ORANGE_HONEY, MUGUET_CYCLAMEN, MUGUET_WATERY_MUSK, PEONY_DEWY, PEONY_ROSE, LILY_SALICYLATE, POLLEN_HONEY, LIGHT_HONEYSUCKLE, LAV_COLOGNE, LAV_BARBERSHOP, LAV_SOFT_MUSK, LAV_SPICED_WOOD, FOUGERE_FLORAL, FOUGERE_TONKA, SANDAL_DRY, PATCH_CLEAN.

These are source-bounded design hypotheses implemented using existing semantic
role templates. They are not botanical reconstructions, exact-grade swaps,
source-fitted allocation rules or measured pleasantness models. Candidate role
weights remain the existing disclosed local heuristic.

Defer YLANG_FRACTIONS, TROP_TIARE, TROP_FRANGIPANI, HERB_ROSEMARY,
VETIVER_HEART and AMBERGRIS_STEREO: broad role templates cannot enforce their
exact species, grade, chemotype or reference comparisons. MAGNOLIA_CREAM needs
a faithful lactonic-texture representation before its named comparison is
executable. Cananga and other identity-sensitive comparisons remain advisory.
No exact CHIMIE L'HOMME target has been recovered; adjacent structures cannot
clear HOLD_EXACT_BRIEF_OR_FORMULA_REQUIRED. Orris Liquid stays excluded.

## Literature reviewed before code changes

Existing source records, exact card hashes and review receipts were read locally.
Their abstract-only, selected-section and legacy-advisory ceilings remain intact.
Review receipts bind local source records, not downloaded publisher-page bytes.
No source or review record is silently rewritten or promoted.

Fresh primary reads supporting the selected comparisons:

  not equivalence with sambac or a measured jasmine reconstruction.
- [Symrise Rose Oxide L](https://www.symrise.com/fileadmin/symrise/Marketing/Scent_and_care/Aroma_molecules/Ingredient_finder/SYM_PC_Datenblaetter/SYM_PC-Rose_Oxide_L.pdf):

- [IFF clary sage](https://www.iff.com/scent/lmr-compendium/sage-clary-oil-france/)
  and [tonka absolute](https://www.iff.com/scent/lmr-compendium/tonka-bean-absolute/):

- [Exaltolide](https://studio.dsm-firmenich.com/product/exaltolider-pe-941962)

## Whole-path audit and repair

A read-only native review found diagnostic gaps: source branches could forge
option/template/policy lineage, self-consistent role hashes did not establish
the registered transformation, a protection boolean was trusted, unknown kinds
could bypass checks, and physical duplicates or critic-withheld branches could
inflate comparison counts.

Before expansion acceptance:
1. Reproduce these gaps with targeted mutations.
2. Bind external expected schema, fixed predecessor paths/hashes, exact options,
   templates, policy, plan digest and reconstructed roles.
3. Recompute protection using the control, not its claimed boolean.
4. Compare a canonical full control payload; distinguish valid withheld
   diagnostics from viable distinct proposals.
5. Keep v1/v2 corpus bytes and paths fixed; freeze a v3 successor corpus before
   its execution. Include predecessor prompts, new mappings and negative-space
   cases. Run network-disabled serial/reversed comparison on current code.
6. Bind all three manifests in durable fingerprints and test drift/disappearance.
7. Run focused tests, scoped lint/type checks and quick project verification.
   Preserve protected input hashes and the dirty worktree. No full release claim.

## Acceptance

A pass establishes reproducible source-bound executable alternatives, unchanged
controls and truthful withholding. It does not establish that a flower is
realistic, CHIMIE L'HOMME reconstructed, a scent improved, or every research
subtype executable. Document measured coverage and remaining limits explicitly.
