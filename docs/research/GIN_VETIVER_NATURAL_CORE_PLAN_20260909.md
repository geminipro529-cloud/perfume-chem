# Natural-core computational candidate pass

User-approved continuation: compare vetiver-bodied, gin-forward developed-base,
and rounded woody-vetiver interpretations; select one computational proposal.
No preliminary physical mixture is required. No compounding release is implied.

## Boundary and implementation

1. Retain the v4 18-stock parent and current inventory authority. No new stock,
   DEP addition, worktree, or pipeline script. Carrier-bearing and unresolved
   proprietary stocks remain fixed; their absence from prediction is explicit.
2. Extend the existing portfolio adapter with hash-bound representative natural
   profiles and PubChem connectivity. Aggregate identical molecules. Preserve
   unresolved residuals without renormalization. Fractions are nominal proxies,
   not density-verified w/w concentrations or lot assays.
3. Compare three engineer-declared allocation envelopes, not learned target
   proportions. Search broadly within each. The baseline is a comparator only.
4. Evaluate nominal and composition-stress scenarios. Retain learned endpoint
   vectors and extrapolation diagnostics. Scenario ranges are not confidence
   intervals. Pleasantness can guide exploration, not certify liking, richness,
   layering, or whole-perfume success. Review Pareto alternatives across scenarios.
5. Select one candidate explicitly by engineering judgment against the brief;
   preserve the parent. Publish the vector, quantities, tradeoffs, source hashes,
   and remaining unknowns in a computational proposal, not a mixing card.

## Tests and stopping point

Test molecule aggregation, residual accounting, malformed profiles, source drift,
frozen omitted stocks, scenario closure, and Pareto dominance. Run existing CLI
and focused regressions. Finish this pass when all three envelopes have an actual
search receipt and one justified computational proposal has been recorded, or
report the specific failed execution step. Do not require sensory data as an
entry condition or endlessly refit the evidence to the starting proportions.
