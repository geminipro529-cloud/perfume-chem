# Source-bound architecture bridge — implementation plan

Date: 2026-10-07. Status: bounded implementation verified; continuing research remains active.

Acceptance and limits: [verified implementation report](ARCHITECTURE_BRIDGE_REVIEW_20261007.md).

## Evidence and defect

The current Deep Compose loop changes stock choices but passes the same
SemanticBrief to every solve. Subtype cards are available in optional research
details, not executable architecture alternatives. Static independent reviews
confirmed that source material examples are not inventory aliases and that role
shares/caps directly feed the dose allocator.

The local reviewed v4 knowledge is reused. A fresh primary-source check of
lychee cultivar research (DOI 10.1021/jf062925p), fig organ profiling
(DOI 10.1016/j.foodchem.2010.04.064), and freesia cultivar work
(https://pmc.ncbi.nlm.nih.gov/articles/PMC8347352/) supports preserving distinct
target facets and domains, not converting source compositions to perfume ratios.
Direct publisher access was incomplete; indexed primary abstracts/sections were
available. Existing source reviews are not silently promoted by this recheck.

## Implementation contract

1. Add a versioned, strict local adapter manifest. Bind each mapping to the exact
   canonical subtype card and its source bindings. Mapping vocabulary is an
   explicitly authored design heuristic, separate from source findings.
2. Keep the original compiled brief as control. In Deep Compose, generate up to
   two source-bound architecture alternatives using named local allocation
   templates. Never parse a paper or card's prose for numeric shares or doses.
3. Add target-linked comparison roles only in unprotected optional slots or
   available capacity. Never remove explicit anchors, prompt-derived facets or
   required opening/heart/base coverage; honor preserve/avoid and exact counts.
4. Record a canonical executable role-plan signature. Rewording labels or
   reordering the same roles is not a new architecture.
5. Pass each candidate's own brief through solving, critique and reporting.
   Keep failures visible and alternatives unordered. Generic stock alternatives
   remain explicitly distinguished from research architecture comparisons.
6. Preserve exact stock/quantity and compounding-hold gates. New research roles
   cannot impersonate prompt-derived roles to bypass potent-trace restrictions.
   A matched unresolved campaign cannot be silently reconstructed.
7. Expose one concise branch explanation in the existing variant UI, using safe
   text rendering. Bind adapter and implementation bytes into job fingerprints.
8. Verify strict schemas, source drift, closed templates, negative requests,
   protected roles, measurable quantities, role diversity, per-variant critique,
   deterministic replay, API delivery and unchanged inventory/formula files.

## Scope and authority

This is a bridge from reviewed guidance to testable structural candidates, not
an empirical composition model or a release. Fast Sketch remains unchanged
unless a hard campaign-identity conflict is found; the comparison behavior is
within the existing explicit Deep Compose workflow. No standalone pipeline
scripts, inventory writes, physical mixing, trained models or safety approval.
Existing numeric allocation templates remain heuristic and are separately
versioned/fingerprinted. No source supports a claim that a generated alternative
smells better. The continuing research goal remains active.
