# Basket Order Preference

> **Purpose:** Persistent record of the user's physical basket order when compounding.
> When a recipe is written or reordered, the material table and pour sequence must
> follow the physical basket category order first. Within each basket, sort raw
> transfer volume from highest to lowest so the dispenser setting only moves down
> while that basket is being compounded.

## Basket category order

1. **Always used** (Hedione, Hedione HC, high-quality patchouli, Iso E Super, vetiveryl acetate, vetiver EO Haiti, Ambrofix, Ambrox Super, patchouli light oil, Ambermax, Vetival, benzyl salicylate, benzyl benzoate, hexyl salicylate)
2. **Vetivers** (vetiver EO, vetiveryl acetate, Vetival)
3. **Woods**
4. **Wood modifiers and ambers** (ambrofix, ambrox super, Ambermax, Vertofix, Amberwood F, etc.)
5. **Wood-vetivers**
6. **Musks**
7. **Muguet and lavender**
8. **Jasmine, indole, and magnolia**
9. **Ylang, orange flower, and narcotics**
10. **Rose**
11. **Iris and orris**
12. **Edible smells** (chocolate, etc.)
13. **Edible spices**
14. **My favorite smells**
15. **Fruits**
16. **Aldehydes**
17. **Green smelling things**

## Basket-first compounding-volume order

Sort every dose-bearing material first by the documented physical basket category
order. Then, within each basket, sort its raw transfer `Amount (µL)` from
**highest µL to lowest µL**. Apply this rule to both the master formula and every
scaled compounding card. The dispenser setting may be reset when moving to the
next basket, but within a basket it must only move downward.

Keep every basket contiguous and finish it before moving to the next basket.
Show the basket number/category alongside every material.

Carriers and solvents may remain in a separate pre-charge block when required
by the compounding method. If that block contains more than one transfer, sort
it from highest raw µL to lowest raw µL as well.

For equal raw-volume transfers within the same basket, use ingredient name as the
tie-breaker. Never change a dose, stock strength, active ppm, or total merely to
alter the order.

## Applied example

If Basket 1 contains 250 µL and 40 µL transfers and Basket 2 contains 600 µL and
250 µL transfers, the pour order is Basket 1: 250 → 40 µL, then Basket 2:
600 → 250 µL. Basket order is primary; descending raw volume applies inside each
basket.

## Rule

When writing or reordering any recipe, use the documented basket category order
as the primary sequence. Inside every basket, list the highest raw `Amount (µL)`
first and the lowest last. Apply the same descending-volume rule inside any
separate carrier pre-charge basket/block. Keep all doses, active ppm, and totals
unchanged.
