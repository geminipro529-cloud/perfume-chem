# Scientific and Source Basis

This file records the main public evidence used to justify the workflow. It does not authenticate any proprietary perfume formula.

## Mixture nonlinearity

1. [Revisiting psychophysical work on the quantitative and qualitative odour properties of simple odour mixtures: Part 1](https://consensus.app/papers/revisiting-psychophysical-work-on-the-quantitative-and-ferreira/fbb50bd17b4d592cbd5e1f753f7cf083/?utm_source=chatgpt) — V. Ferreira, 2012, *Flavour and Fragrance Journal*, 127 citations in the retrieved index. The review reports suppression, hypoaddition, and the potential for peri-threshold components to change mixture quality.
2. [The perception of odor objects in everyday life](https://consensus.app/papers/the-perception-of-odor-objects-in-every-life-a-review-on-thomas-danguin-sinding/c9470ac46b485864b671021295931fbb/?utm_source=chatgpt) — T. Thomas-Danguin et al., 2014, *Frontiers in Psychology*, 227 citations in the retrieved index. Complex mixtures can be processed as odor objects rather than simple elemental sums.
3. [Competitive binding predicts nonlinear responses of olfactory receptors to complex mixtures](https://consensus.app/papers/competitive-binding-predicts-nonlinear-responses-of-singh-murphy/8d20b2ac2eda59749b6daf16b83fe3a9/?utm_source=chatgpt) — Vijay Singh et al., 2018/2019, *PNAS*, 73 citations in the retrieved index. Competitive binding provides a mechanistic model for nonadditive receptor responses.

## Matrix and temporal release

4. [Headspace SPME-GC-MS analysis of scent profiles from human skin](https://consensus.app/papers/headspace-solidphase-microextraction-gas-duffy-albero/907412b2c1885854bdbbdf9fc39317d3/?utm_source=chatgpt) — E. Duffy, Gwendoline Albero, and A. Morrin, 2018, *Cosmetics*, 28 citations in the retrieved index. Fragrance release changes over time and varies across skin.
5. [Impact of interactions between fragrances and cosmetic bases on olfactory performance](https://consensus.app/papers/impact-of-the-interactions-between-fragrances-and-nicolantonio-gigliobianco/516fdbbce0905e8390d74170f897e1ef/?utm_source=chatgpt) — Lucrezia Di Nicolantonio et al., 2022, *Cosmetics*, 10 citations in the retrieved index. Matrix composition changes volatile release and sensory performance.
