# Cost-Effective Session

1. Read `AGENTS.md` and preserve unrelated local edits before changing files.
2. Keep plugins off unless a plugin provides unique data, authorization, or browser/runtime capability.
3. Use local `rg`, bounded reads, diffs, and focused tests before paid model or broad verifier work.
4. Reuse exact local evidence when the source files, command, and acceptance criteria are unchanged.
5. For delegated reads, use DeepLuna with `reuse_cache: true`, `FLASH`, explicit allowed paths, bounded output, and stable instructions before volatile repo state.
6. Batch two or more independent evidence nodes with concurrency one by default; use concurrency two only for clear wall-clock benefit.
7. Use Pro write delegation only for one frozen-interface leaf change with explicit allowlisted paths and local verification afterward.
8. Let Luna run only through the DeepLuna fallback gate; do not start a separate Luna path for the same accepted job.
9. Run the cheapest sufficient verification rung first, then escalate only when behavior changed or a publication/release claim needs it.
10. Fresh completion claims require fresh applicable verification; cache can reduce investigation cost, not replace acceptance evidence.
