## Mixing Order

1. **⚠️ PRE-BLEND**: 52.5µL AIMI + 122.5µL IPM → 175µL AIMI 30%
2. Add 24 mL ethanol to 30mL bottle
3. **Scaffolding** (#1–3): Benzyl Benzoate → Ambrox Super → Farnesol
4. **Base** (#4–10): Iso E Super → Hedione → Cedarwood → Tonka Absolute → Galaxolide → Vetiver → Ambrettolide
5. **Heart** (#11–17): Alpha Irone → AIMI 30% → Rose EO → Parmavert → Citral → Clove EO → Isoeugenol
6. **Top** (#18–21): Ginger EO → Bergamot FCF → Neroli EO → Calone
7. Shake gently after each group. Mature 4–6 weeks.
