## Optimization Summary

The original `NL-04` concept was elegant but slightly under-lit. The engine read it as:
- too base-heavy for the intended golden-floral effect
- not enough top lift for the champaca opening
- too much powdery/woody ballast from the ionone-sandalwood side

### Engine-Led Changes Applied

- **Cedrat FCF oil Sicilian** increased from `60 µL` → `150 µL`
- **Cardamom FTEC (10%)** increased from `60 µL` → `120 µL`
- **Hedione** increased from `240 µL` → `320 µL`
- **Benzyl Acetate** reduced from `70 µL` → `40 µL`
- **Benzyl Salicylate** reduced from `130 µL` → `90 µL`
- **Alpha Isomethyl Ionone** reduced from `100 µL` → `40 µL`
- **Javanol** reduced from `90 µL` → `50 µL`
- **Ebanol** reduced from `70 µL` → `35 µL`
- **Amberwood F** reduced from `80 µL` → `40 µL`
- Added **Bergamot FCF oil Sicilian** at `30 µL`
- Added **Linalool** at `20 µL`
- Added **Nympheal** at `20 µL`
- Added **Rose Oxide (1%)** at `10 µL`

### Predicted Impact

- Total score: `70.1` → `75.8`
- Balance: `69.6` → `87.4`
- Sillage: `63.0` → `76.4`
- Theory: `75.0` → `82.0`
- Synergy: `52.6` → `58.8`
- Radiance: `49.7` → `52.1`
- Note distribution: `Top 4.1 / Heart 43.9 / Base 52.0`
  → `Top 13.3 / Heart 44.5 / Base 42.3`

### What Changed Artistically

The formula now reads less like a powdery floral-wood and more like a polished golden-floral perfume:
- brighter citrus-mineral opening
- clearer cardamom-champaca lift
- less violet-powder drag
- a smoother sandalwood-musky base that supports the floral instead of weighing it down

The engine produced **no further high-impact pre-mix recommendations** after this pass.

## Step-by-Step Mixing Instructions

### Phase 1: Prepare the Workspace

1. Clean the bench and glassware with ethanol.
2. Set out all materials in order of addition.
3. Label the bottle: `Champaca d'Or Moderne (Optimized) / 30 mL / 17.45% / [Date]`.
4. Wear gloves before handling the floral and salicylate materials.

---

### Phase 2: Build the Base

This phase creates the polished wood-musk floor first so the floral heart has a stable frame.

5. Add **Iso E Super** — `660 µL`
6. Add **Habanolide** — `360 µL`
7. Add **Galaxolide (80%)** — `450 µL`
8. Add **Amberwood F** — `120 µL`
9. Add **Javanol** — `150 µL`
10. Add **Ebanol** — `105 µL`
11. Add **Alpha Isomethyl Ionone** — `120 µL`
12. Stir gently for `20-30` seconds.

**Checkpoint:** The base should smell smooth, clean, lightly sandalwooded, and only softly powdery.

---

### Phase 3: Build the Floral Heart

13. Add **Benzyl Salicylate** — `270 µL`
14. Add **Hedione** — `960 µL`
15. Stir `15` seconds.
16. Add **Champaca Flower EO** — `360 µL`
17. Add **Ylang Comoros III EO F3295** — `240 µL`
18. Add **Methyl Benzoate** — `210 µL`
19. Add **Cis Jasmone** — `60 µL`
20. Add **Nympheal** — `60 µL`
21. Add **Benzyl Acetate** — `120 µL`
22. Add **Rose Oxide (1%)** — `30 µL`
23. Stir `30` seconds.

**Checkpoint:** The heart should smell golden, tea-like, floral, diffusive, and cleaner than the original draft.

---

### Phase 4: Add the Top Lift

These go in after the heart so the brighter materials stay sharper.

24. Add **Cedrat FCF oil Sicilian** — `450 µL`
25. Add **Bergamot FCF oil Sicilian** — `90 µL`
26. Add **Cardamom FTEC (10%)** — `360 µL`
27. Add **Linalool** — `60 µL`
28. Stir `20` seconds.

**Checkpoint:** The opening should now feel brighter, more mineral-citrus, and more clearly perfumed.

---

### Phase 5: Dilute

29. Confirm the concentrate volume is `5.235 mL`.
30. Add **Ethanol 96%** — `24.765 mL`
31. Stir for `60` seconds until fully homogeneous.
32. Check clarity. The liquid should be clear with no cloudiness.

---

### Phase 6: Bottle and Rest

33. Transfer to the bottle with a funnel.
34. Cap tightly.
35. Shake vigorously for `30` seconds.
36. Store in a cool, dark place.

## Expected Olfactive Development

Bright cedrat and bergamot with cardamom lift. The opening is no longer underpowered; it now has enough sparkle to announce the perfume before the floral heart arrives.

### Heart

Champaca and ylang create the golden floral body. Methyl Benzoate and Cis Jasmone make the floral accord feel more alive and expensive rather than thick or old-fashioned. Hedione and Nympheal provide the halo.

### Drydown

The base is cleaner and less powder-heavy than the original draft. Javanol, Ebanol, Iso E Super, Habanolide, and Galaxolide create a polished sandalwood-musky skin effect rather than a dense woody block.
