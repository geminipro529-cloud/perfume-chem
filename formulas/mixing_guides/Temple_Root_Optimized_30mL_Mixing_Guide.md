## Optimization Summary

This is a **shell-only optimization**.

The `Opus V Iris Accord` was treated as a **fixed reusable module**:
- accord dose held at `2.40 mL`
- internal accord ratios held unchanged
- only the outer perfume shell was adjusted

That is the correct optimization method if the accord is going to be reused across multiple perfumes.

### Why The Original Needed Work

The original `Temple Root` concept was strong, but the outer shell was:
- too base-heavy
- too under-lit in the opening
- slightly over-supported by extra dry woods and powder bridges outside the accord

The accord itself was not the problem. The frame around it was.

### Engine-Led Changes Applied To The Outer Shell

- `Bergamot FCF oil Sicilian` increased from `90 µL` -> `180 µL`
- added `Cedrat FCF oil Sicilian` at `90 µL`
- added `Linalool` at `60 µL`
- added `Aldehyde C12 MNA (1%)` at `30 µL`
- added `Jasmine FO` at `30 µL`
- `Hedione` increased from `180 µL` -> `330 µL`
- `Cedramber` reduced from `540 µL` -> `360 µL`
- `Clearwood` reduced from `420 µL` -> `300 µL`
- `Ambrofix (30% w/v)` reduced from `180 µL` -> `120 µL`
- `Bacdanol` reduced from `150 µL` -> `120 µL`
- `Heliotropin Fleuressence` reduced from `60 µL` -> `30 µL`
- `Coumarin (20%)` reduced from `90 µL` -> `60 µL`

1. Add the structural cushion:
   `Bacdanol`, `Coumarin (20%)`, `Ambrox Super (30% w/v)`, `Vetival`, `Heliotropin Fleuressence`.

9. Rest `7 days` minimum.

## Why This Version Is Better

### 1. The accord stays the star

The accord remains unchanged and still provides:
- the buttery irone core
- metallic orris-concrete chill
- rooty waxy body
- the small shadow base inside the iris itself

The shell no longer overcompetes with that.

### 2. The opening finally exists

The original shell was too heavy too early.

Now the top has a proper but controlled lift from:
- `Bergamot FCF oil Sicilian`
- `Cedrat FCF oil Sicilian`
- `Linalool`
- `Aldehyde C12 MNA (1%)`
- `Black Pepper FTEC`

This still does not turn `Temple Root` into a fresh fragrance. It just gives the incense-iris opening enough light to register before the base takes over.

### 3. The heart breathes better

`Hedione` was the most important increase in the shell.

It gives:
- more interior space
- better iris projection
- less collapse from incense directly into dry wood

The tiny `Jasmine FO` addition is not there to make this floral. It is there as a bridge so the accord reads more like a complete perfume and less like an isolated module glued onto a base.

### 4. The redundant shell ballast was cut back

The accord already contains some of the softness and powder support:
- `Bacdanol`
- `Heliotropin Fleuressence`
- `Coumarin`

So the optimized shell trims those supports rather than stacking them too heavily outside the accord.

The same logic applies to:
- `Cedramber`
- `Clearwood`
- `Ambrofix`

The original shell had too much dry support mass. The optimized shell still has structure, but it stops smothering the accord.

## Step-by-Step Mixing Order

### Phase 1: Dry Wood Structure

Add and stir:
1. `Iso E Super` — `1.10 mL`
2. `Cedramber` — `0.36 mL`
3. `Clearwood` — `0.30 mL`
4. `Ambrofix (30% w/v)` — `0.12 mL`
5. `Vetival` — `0.10 mL`
6. `Bacdanol` — `0.12 mL`

This should smell dry and polished, but less overbuilt than the original draft.

### Phase 2: Resin-Root Frame

Add and stir:
7. `Olibanum Resinoid` — `0.45 mL`
8. `Myrrh EO` — `0.24 mL`
9. `Labdanum Absolute (10%)` — `0.24 mL`
10. `Patchouli EO` — `0.18 mL`
11. `Vetiver EO` — `0.18 mL`

This is still the temple backbone. It was intentionally not stripped down.

### Phase 3: Diffusion And Floral Bridge

Add and stir:
12. `Benzyl Salicylate` — `0.33 mL`
13. `Habanolide` — `0.27 mL`
14. `Galaxolide (80%)` — `0.27 mL`
15. `Hedione` — `0.33 mL`
16. `Jasmine FO` — `0.03 mL`
17. `Heliotropin Fleuressence` — `0.03 mL`
18. `Coumarin (20%)` — `0.06 mL`

This phase is where the optimized version opens up.

### Phase 4: Iris Core

Add and stir thoroughly:
19. `Opus V Iris Accord` — `2.40 mL`

At this point the perfume should read unmistakably as a dark iris composition rather than an incense-wood scent.

### Phase 5: Top Polish

Add last before dilution:
20. `Cedrat FCF oil Sicilian` — `0.09 mL`
21. `Bergamot FCF oil Sicilian` — `0.18 mL`
22. `Linalool` — `0.06 mL`
23. `Black Pepper FTEC` — `0.03 mL`
24. `Aldehyde C12 MNA (1%)` — `0.03 mL`

This top is still restrained. It is polish, not cologne architecture.

### Phase 6: Final Dilution

25. Add `Ethanol 96%` — `22.50 mL`
26. Stir or shake thoroughly for `60-90 seconds`
27. Bottle in glass

## Remaining Optimization Boundary

The engine still wants even more top and heart material, but pushing much further starts to move the perfume away from the `Temple Root` idea.

That means this version is a better optimization boundary for the concept:
- improved technically
- still faithful artistically
- still modular around the reusable accord

If you want to push performance further after testing, the next likely moves would be:
- `+30-60 µL` more `Cedrat FCF oil Sicilian`
- `+30 µL` more `Aldehyde C12 MNA (1%)`
- or `+30 µL` more `Jasmine FO`

But I would not do that before smelling this optimized version first.
