# Opus V Iris Crystal - Exact 2400uL Batch Guide

**Purpose:** mix exactly the amount of `Opus V Iris Crystal` needed for one `30mL` Aperture bottle  
**Target Batch:** `2400 uL` total

---

## Mixing Order

1. Combine the heavy iris body:
   `Orivone`, `Methyl Ionone Pure`, `Orris F-TEC`, `I-IRIS F-TEC`, `Allyl Ionone (Ketone V)`, `Dihydro Beta Ionone`, `Irotyl`, `Ultralia`.
2. Add the irone / ionone layer:
   `Alpha Irone (10%)`, `Alpha Ionone`, `Beta Ionone`.
3. Add `Bacdanol`.
4. Add `Hedione`.
5. Add `Carrot Seed EO`.
6. Add `Rose Oxide (1%)` last.
7. Rest at least `7 days`; `14 days` is preferable.

---

## Notes

- This is the exact crystal batch used by the Aperture formula.
- It is intentionally small so you do not have to make a large surplus.
- If you want to make a spare backup batch, make a second identical `2400 uL` lot rather than scaling the main perfume recipe.
