## TARGET / IDEAL

The perfume is built as one continuous, layered object rather than a pineapple accord. All materials are compounded into one vessel; the layers below are olfactive and temporal relationships, not separate premixes:

1. A dry transparent wood–amber–musk spine carries the full evaporation curve.
2. Bergamot and blackcurrant absolute state the primary opening.
3. Pineapple is a short green-fruit transition into the heart, never the subject.
4. Pink pepper and jasmine radiance bridge the head into a smoky, leathery patchouli base.
5. A salicylate–jasmine interior prevents the head from falling directly into the base.
6. The base returns in distinguishable registers: literal cedar/patchouli, mineral amber-wood, smoke/suede, moss-green contour, and one persistent musk.

No commercial percentages are asserted by this target. Birch tar is an ideal reference function only; it is excluded from this build because the live inventory marks that stock prohibited.
