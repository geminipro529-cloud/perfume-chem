# MR. SANDMAN — *Lullaby in Yellow*
**Family:** Powdery Floral-Gourmand — Retro-Cosmetic Lullaby subgenre
**Brief:** The dreamy jingle that plays as the film reel ends — warm cinema-seat nostalgia, a yellow cashmere blanket, powdered cheeks, and the slow drift into sleep against someone's shoulder. Retro-glamour aldehydic lipstick top (preserved exactly from the original). Jasmine body rebuilt with DBCA, iris rebuilt with Orris F-TEC + Myristic Acid chemistry, muguet upgraded to Nympheal, rose expanded to 4-axis, sandalwood cream (Polysantol) and 5-musk chord added.
**Created:** 2026-04-25 · **Rebuilt:** 2026-05-10 — *families remade with best-in-inventory molecules. Top signature untouched. No Myristic Acid (that's Jasmin d'Orris). Transparent ghost-iris veil preserved.*

---

## Design Rationale

"Mr. Sandman" lives in 1950s technicolor warmth. The correct register is **powder + marshmallow + cashmere-textile + waxy-floral lipstick aldehyde**. The top aldehydic signature (C11 lipstick + C12 sparkle + Bergamot Sicilian + Mandarin) is the perfume's identity — untouched from the original.

Every other family has been rebuilt with the single best molecule in inventory for each role. No 7-ionone iris wall — just Alpha Irone (the star) + Orris F-TEC (the base) + Orivone (the butter) + Myristic Acid (the chemistry). No one-dimensional damascone rose — 4-axis rose. No dated hydroxycitronellal muguet — radiant Nympheal.

## Compounding Order

**Stage A — Base**: Ethylene Brassylate → Iso E Super → Romandolide → Polysantol → Azarbre → Vertofix → Cashmeran 20% → Ambrettolide 10% → Exaltolide 10% → Musk Ketone 10% → Siam Benzoin 50% → Costus Olifac 10% (25 µL) → Scentenal 1% (10 µL). Swirl.

**Stage B — Fixative**: Hexyl Salicylate. Swirl.

**Stage C — Hedione**: 1.650 g. Swirl.

**Stage D — Iris block**: Alpha Irone 30% → Orivone → Ultralia. Swirl.

**Stage E — Powder jingle**: Heliotropal (warm if solid) → Anisaldehyde → Coumarin 20% → Vanillin 10% → Ethyl Maltol 10%. Swirl.

**Stage F — Muguet + Rose + Jasmine**: Nympheal → Mayol → PEA → Geraniol → Damascol 10% → Rose Oxide 10% → DBCA → Farnesol. Swirl.

**Stage G — Top (LAST, minimise volatilisation)**: Bergamot Sicilian → Red Mandarin → Aldehyde C12 MNA 1% → Aldehyde C11 undecylenic. Cap within 60 seconds.

**Stage H — Rest 48h, dilute with ethanol 96% to 50 mL, macerate 4-6 weeks, cold-filter.**
