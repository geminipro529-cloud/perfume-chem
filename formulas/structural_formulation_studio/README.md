## Formula Representations

Every perfume has two separate representations:

- **TARGET / IDEAL:** inventory-independent structural target in normalized active ppm. It describes the intended object and functions; it is not a shopping list.
- **CURRENT-INVENTORY:** a theory build limited to physically authorized materials and explicitly described working-stock assumptions. It must include a gap map back to TARGET / IDEAL.

Never collapse the two tables. Availability is not evidence of fit, and an unavailable ideal material is not permission to procure it.

## Batch Workflow

1. Complete the batch ledger and stop on unresolved authority conflicts.
2. Write the named identity contract and takeover exclusions.
3. Build the subject/state, spatial, temporal, texture, pressure/release, base, and hedonic maps.
4. Write TARGET / IDEAL before considering inventory.
5. Translate to CURRENT-INVENTORY and document every gap.
6. Admit each material through the function and omission gate.
7. Check raw totals, nominal active ppm, 10 uL floor, musk count, ODT/physics coverage, composite naturals, and safety-data authority.
8. Run the local pipeline as a diagnostic and append its full formatted output.
9. Design constant-total blinded arms before any future physical work.
10. End with the exact status: **THEORY ONLY / NOT TESTED / NO COMPOUNDING AUTHORIZED**.
