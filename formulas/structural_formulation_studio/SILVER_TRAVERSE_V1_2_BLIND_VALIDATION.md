8. test the one musk against no musk.

### 2 x 2 inference

For a pre-declared endpoint score within each independent block:

```text
P main effect = ((P+R- + P+R+) - (P-R- + P-R+)) / 2
R main effect = ((P-R+ + P+R+) - (P-R- + P+R-)) / 2
P x R interaction = P+R+ - P+R- - P-R+ + P-R-
```

The full reconstruction survives only if the interaction repeatedly improves one integrated rosy-effervescent pepper subject and Silver Traverse identity without increasing hot/dry pepper, literal rose/plum, harshness, fatigue, or fragmentation. A liked but non-Pink-Pepper-like arm fails the protected criterion.
