# Good Girl Gone Bad — 30 mL Eau de Parfum

**Batch:** 30.00 mL · ~18.3% EdP · 48 materials
**Profile:** By Kilian — Good Girl Gone Bad (2012, Alberto Morillas). Osmanthus-peach luminous opening, three-sirens white floral heart (tuberose + jasmine + narcissus + rose), woody-amber-musk drydown.
**Maceration:** 4 weeks minimum

---

## Equipment

- 1 amber glass bottle 30 mL
- 1 graduated pipette 1 mL (for 100–600 µL volumes)
- 1 micro-pipette or 1 mL syringe graduated 0.01 mL (for 5–80 µL volumes)

## Maceration

Minimum 4 weeks. White floral complexes need integration time. The osmanthus-peach top reaches full bloom at 3 weeks; the tuberose trio emerges at 4+.

---

## Accord Architecture

### Top — Luminous peachy-citrus (the "Good Girl")
Bergamot FCF + Red Mandarin create a warm transparent citrus opening. The osmanthus effect is built from Apritone (apricot) + Gamma Decalactone (peach) + Gamma Undecalactone (creamy peach) + Paradisamide (tropical radiance) + Methyl Anthranilate (fruity grape-floral). Aurantiol + Oranger Crystals provide the neroli/orange blossom lift. Petitgrain adds green-bitter structure. Bright, fruity, luminous — the innocent facade.

### Heart — The Three Sirens (the "Gone Bad")
**Tuberose:** p-Cresyl Methyl Ether (3.5 µL active) + Methyl Benzoate + Indole (5 µL active) + Ylang Ylang complete EO. Creamy, indolic, slightly medicinal tuberose signature.
**Jasmine:** Hedione (550 µL) + Hedione HC + Benzyl Acetate + Cis Jasmone + Dihydrojasmone + Indole trace. Morillas' radiant sparkling jasmine.
**Narcissus:** PEDMC + Farnesol + green rose elements. Waxy-green floral complexity.
**Rose de Mai:** Geraniol + Citronellol + Nerol + Rhodinol + PEA + Rose Oxide + Damascone Beta. Full luxurious rose supporting rather than dominating.
**Muguet whispers:** Mayol + Heliotropal add transparent floral powder.

### Base — Woody-amber-musk cocoon
Four-musk chord: Galaxolide (clean projection) + Ethylene Brassylate (lactonic body) + Habanolide (warm skin) + Ambrettolide (skin whisper). Three-material sandalwood: Javanol (creamy) + Ebanol (soft) + Sandalore (fresh). Cedarwood Virginia backbone. Patchouli + Vetiver for dark earthy depth. Ambermax + Labdanum + Benzoin + Vanillin + Coumarin for warm amber-vanillic base. Cashmeran for textile warmth. Iso E Super for velvety diffusion.
