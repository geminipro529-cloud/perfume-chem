# Ylang Sans Champaca — 5 Ylang-Dominant Current-Inventory Formulas

**Date:** 2026-04-03  
**Batch Size:** 10.00 mL each  
**Format:** Ready-to-mix trial formulas  
**Rule:** Every formula below uses `Ylang Comoros Complete EO F3255` and/or `Ylang Comoros III EO F3295`, uses **no** `Champaca Flower EO`, and keeps ylang as a **main character**, not a trace accent.

This file replaces the earlier lighter set. Your criticism was correct: if the formula is supposed to be a ylang perfume, ylang needs to sit much closer to the center of the concentrate.

In this revised set, ylang load is roughly:
- `10.6%` to `14.7%` of the concentrate

That is enough for the perfume to actually read as ylang-led.
