**Date:** 2026-04-03  
**Batch Size:** 10.00 mL each  
**Format:** Ready-to-mix trial formulas  
**Design Rule:** Every formula below treats `Cis Jasmone` as an explicit `Star` or `Sub-Star`, not as a trace afterthought.

**Sequel:** For 30 additional variations, see [`Cis_Jasmone_Collection_Vol_2_30.md`](/d:/chatbots/perfume-chem/Cis_Jasmone_Collection_Vol_2_30.md).

This set is split into:
- `NL-01` to `NL-10`: niche-luxury
- `LM-11` to `LM-20`: luxury-mass
- `NM-21` to `NM-30`: niche-mass bridge formulas

All formulas use only current inventory materials from [`inventory.txt`](/d:/chatbots/perfume-chem/inventory.txt).

---

## Cis Jasmone Positioning

- `Star` formulas use roughly `40-60 µL` cis Jasmone per 10 mL formula.
- `Sub-Star` formulas use roughly `30-35 µL` cis Jasmone per 10 mL formula.
- This still keeps the material workable, but it finally puts it in a true feature/subfeature role.
