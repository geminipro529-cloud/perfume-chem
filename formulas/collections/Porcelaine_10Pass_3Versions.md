**Base Formula:** Porcelaine (Optimized) — Luxury Cosmetic Plastic Floral

**Hard Gate:** Porcelaine DNA must survive every pass  
**Batch Size:** 30.00 mL per version  
**Date:** April 19, 2026

---

## Porcelaine DNA Hard Gate — Definition

The "porcelaine DNA" is the cosmetic-plastic floral identity. Every optimization pass must preserve:

| Gate | Criterion | Test |
|------|-----------|------|
| **G1** | DBCA + Benzyl Salicylate + Hedione(s) backbone | ≥ 2,400 µL absolute (unchanged from original) |
| **G2** | Muguet transparency | ≥ 3 muguet materials present (from: Lilyreal, Nympheal, Bourgeonal, Hydroxycitronellal, Freesia HDI, Mayol) |
| **G3** | Salicylate cushion | ≥ 8% of concentrate from salicylate materials |
| **G4** | No dark/animalic intrusion | Zero materials from leather, smoky, indolic, or fecal registers |
| **G5** | No gourmand overload | Sweet/lactonic materials ≤ 8% of concentrate (active mass) |
| **G6** | Laundered top preserved | Ethyl Linalool + Linalool + Bergamot citrus frame intact |

**Gate violation = pass rejected.** No exceptions.

## The 10-Pass Optimization Framework

Each pass targets one specific weakness in the original Porcelaine. The 3 versions differ in how aggressively each pass is applied.

### Pass 1: Powder Foundation

**Weakness:** Original has zero powder-axis materials — reads as "clean floral" not "powdery luxury."

**Material evaluated:**
| Candidate | Character | Verdict |
|-----------|-----------|---------|
| Heliotropin Fleuressence | Sweet-almond-powdery, THE face-powder-compact effect | **SELECTED** — directly creates the luxury compact powder effect |
| Heliotropal (Piperonal) | Deeper almond-vanilla-heliotrope, less purely "powdery" | Selected for Version C only — adds almond depth under Heliotropin |
| Coumarin (20%) | Hay-warm powder — different register | Moved to Pass 3 (separate coumarinic axis) |
| Vanillin | Too sweet, too gourmand | **REJECTED** — violates G5 sweet gate |

**Action:** Add Heliotropin Fleuressence (neat). Version C also adds Heliotropal for dual-powder chord.

**Gate check:** Heliotropin is powder, not sweet in the gourmand sense. Gate G5 holds. All other gates untouched. ✓

### Pass 2: Violet-Powder Luminosity

**Weakness:** No ionone-type material — missing the violet-powder transparency that defines luxury cosmetics (Chanel, Dior, Guerlain all use ionones for this).

**Material evaluated:**

|-----------|-----------|---------|

| Orivone | Warm orris-butter, not ionone-powder | Moved to Pass 4 (orris axis) |

**Action:** Add Allyl Ionone (neat). The gentlest available ionone — green-violet diffusive transparency. Less purely "powdery" than the unavailable AIMI, but the powder axis is covered by Heliotropin (Pass 1) + Coumarin (Pass 3) + Musk Ketone (Pass 5). Allyl Ionone contributes violet CHARACTER and transparent diffusion.

**Gate check:** Allyl Ionone is gentler and greener than AIMI but still violet-cosmetic family. Powder contribution is lighter, compensated by other powder materials. All gates hold. ✓

### Pass 5: Musk Chord Refinement

**Weakness:** Current musk chord (Habanolide + Galaxolide + Cashmeran) reads "clean laundry" not "luxury powder." Galaxolide is the detergent-musk — fine for clean character, wrong for high-end luxury.

**Material evaluated:**
| Candidate | Axis | Character | Verdict |
|-----------|------|-----------|---------|
| Musk Ketone (powder) | Character-echo | THE powdery musk, talcum-sweet, directly reinforces powder axis | **SELECTED all versions** — the ONLY musk that echoes powder |
| Ethylene Brassylate | Depth | Creamy, lactonic, buttery, long tenacity | **SELECTED B+C** — replaces Galaxolide's depth role with luxury read |
| Romandolide | Projection | Diffusive, clean, slightly woody-musk | **SELECTED C only** — extends sillage architecture outward |
| Zenolide | — | Citrusy-fresh musk | Rejected — too cold, works against powder warmth |
| Exaltolide (10%) | — | Fatty-skin, animalic-adjacent | Rejected — fatty quality clashes with clean porcelaine |
| Ambrettolide (10%) | — | Fruity-wine, naturalistic | Rejected — too naturalistic/fruity for abstract cosmetic |

**Action by version:**
- **A:** +Musk Ketone 30mg (dissolve in ethanol). Galaxolide unchanged. → Powder-echo musk added to existing chord.
- **B:** +Musk Ketone 40mg, +Ethylene Brassylate 200 µL. Galaxolide 300→200 µL. → Laundry musk reduced, creamy-powder musk added.
- **C:** +Musk Ketone 50mg, +Ethylene Brassylate 250 µL, +Romandolide 150 µL. Galaxolide 300→150 µL. → Full luxury musk rebuild: powder (MK) + cream-depth (EB) + projection (Romandolide). Galaxolide reduced to trace clean-carrier.

**Why Habanolide kept:** Habanolide (depth axis) provides warm-skin intimacy that EB and MK don't cover. It's the skin-musk, EB is the cream-musk, MK is the powder-musk. Three different axes, no redundancy.

**Gate check:** Musk changes reinforce luxury. Galaxolide reduction IMPROVES luxury perception (less detergent). G1-G6 all hold. ✓

### Pass 6: Sandalwood Texture

**Weakness:** No skin-intimate woody texture in the drydown. The base reads as "abstract molecular" (Iso E Super) but lacks the premium skin-scent intimacy that sandalwood provides.

**Material evaluated:**

Ebanol would add warmth that softens the porcelain edge. Version C uses BOTH to create a full sandalwood chord (cold surface + warm interior), but Version B keeps it cold and precise.

**Action:**
- **A:** Skip — keep original abstract base intact (conservative)
- **B:** +Javanol 120 µL (mineral-intimate skin sandalwood)
- **C:** +Javanol 150 µL + Ebanol 100 µL (cold + cream sandalwood chord)

**Gate check:** Sandalwood is transparent and skin-intimate. Does not shift the cosmetic-floral DNA — sits underneath it. ✓

### Pass 7: Fixative Gradient

**Weakness:** Single-layer fixation (Benzyl Salicylate only). A luxury formula needs a GRADIENT: transparent fixative on top, heavy fixative below.

**Material evaluated:**
| Candidate | Character | Verdict |
|-----------|-----------|---------|
| Hexyl Salicylate | Light, green-floral, transparent salicylate film | **SELECTED** — creates adhesion without adding cosmetic weight, sits on top of BenSal |
| Benzyl Benzoate | Near-odorless, pure fixative mass | Rejected — no character, this formula needs its fixatives to contribute cosmetic salicylate character |

**Why Hexyl Salicylate, not more Benzyl Salicylate:** BenSal is heavy and cosmetic-waxy. More BenSal = thicker, heavier. Hexyl Sal is sheer and green-floral. Layering Hexyl Sal OVER BenSal creates a gradient: sheer transparency → deep cosmetic waxy fixation. This is how luxury houses build their salicylate architecture.

**Action:** Add Hexyl Salicylate (neat). This directly reinforces the salicylate cushion (Gate G3) and adds green-floral transparency.

**Gate check:** Hexyl Sal is salicylate family — STRENGTHENS G3. All gates hold. ✓

### Pass 8: Radiance Quality Upgrade

**Weakness:** Standard Hedione is ~20% cis-isomer. Hedione HC is ~75% cis. The cis-isomer is the VN1R1 receptor activator — the "pheromone" effect, the radiance, the three-dimensional bloom. More cis per µL = better quality radiance without adding volume.

**Action:** Swap part of Hedione → Hedione HC. Total Hedione volume unchanged.
- **A:** 200 µL Hedione → Hedione HC (Hedione 1000 + HC 200 = 1200 total)
- **B:** 400 µL swapped (Hedione 800 + HC 400 = 1200 total)
- **C:** 600 µL swapped (Hedione 600 + HC 600 = 1200 total)

**Gate check:** Total volume unchanged. The backbone sum (DBCA + BenSal + Hedione total) is still exactly 2,400 µL. G1 perfectly preserved. ✓

## Mixing Notes — All Versions

### Musk Ketone Handling

Musk Ketone is a crystalline powder. Do NOT add it to concentrate directly.

1. **Measure ethanol first** — pour your ethanol allotment into the beaker
2. **Weigh Musk Ketone** — 30mg (A), 40mg (B), or 50mg (C) on precision scale
3. **Dissolve in ethanol** — sprinkle powder onto ethanol surface, stir 2 minutes until dissolved (Musk Ketone dissolves well in ethanol at room temperature)
4. **Then add concentrate** — build concentrate on top of the Musk Ketone-ethanol solution

The 30–50mg of solid adds negligible volume (< 0.05 mL). No adjustment needed.

### Coumarin (20%) Handling

Coumarin (20%) is pre-dissolved in solvent (DPG or DEP). Use as-is — the solvent is accounted for in the total volume.

- Version A: 200 µL of 20% solution = 40 µL active Coumarin
- Version B: 250 µL = 50 µL active
- Version C: 300 µL = 60 µL active

If your Coumarin (20%) has crystallized, warm the bottle to 40°C in a water bath for 5 minutes and shake before pipetting.

### Alpha Irone (30% in DEP) Handling — Versions B & C

Alpha Irone is 30% in Diethyl Phthalate. The DEP carrier adds ~100-140 µL of inert solvent to the formula — this is accounted for in the concentrate total.

- Version B: 150 µL of 30% solution = 45 µL active Alpha Irone
- Version C: 200 µL = 60 µL active

### Hedione vs Hedione HC

These are the SAME material (methyl dihydrojasmonate) at different isomer ratios:
- **Hedione:** ~20% cis-isomer, standard grade
- **Hedione HC:** ~75% cis-isomer, premium grade

The cis-isomer is the active VN1R1 receptor ligand. More cis = more radiance, more intimate bloom, more "pheromone" effect. The swap is a pure QUALITY upgrade with zero character shift — just better radiance per µL.

Add them sequentially: Hedione first, then Hedione HC on top. They miscible immediately.

### Mixing Order (All Versions)

**Phase 1:** Dissolve Musk Ketone in ethanol (beaker)  
**Phase 2:** Build concentrate in a SEPARATE beaker:
1. Top notes (Bergamot → Linalool)
2. Floral core (DBCA → Hydroxycitronellal, then Mayol if Version C)
3. Powder/orris layer (Allyl Ionone → Coumarin, then Irone/Orivone)
4. Base (Iso E → Javanol/Ebanol)
5. Musks (Habanolide → Cashmeran, EB, Romandolide)
6. Trace materials (Gamma Decalactone, Ultralia)

**Phase 3:** Combine concentrate into MK-ethanol solution. Stir 90 seconds.  
**Phase 4:** Transfer to bottle. Cap. Shake 30 seconds.
