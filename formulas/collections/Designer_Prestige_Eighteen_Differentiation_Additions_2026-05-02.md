# DESIGNER PRESTIGE EIGHTEEN — Differentiation Additions

**Date:** 2026-05-02
**Companion to:** [Designer_Prestige_Eighteen_3K_to_15K_THB_2026-05-02.md](Designer_Prestige_Eighteen_3K_to_15K_THB_2026-05-02.md)
**Purpose:** for each of the 18 v3 prestige builds, identify 2–4 targeted additions from current inventory that lift the build above its commercial benchmark on the 5 axes: **longevity, performance (projection / sparkle / radiance), luxury, depth, texture**.
**Approach:** use materials in [inventory.txt](../../inventory.txt) that the v3 dupe-baselines didn't draw on. Doses kept small (≤2 % of total concentrate per addition) so the addition flexes a specific axis without changing the build's family identity. Each addition is annotated with the axis it boosts and the rationale.

**IFRA carryover:** all proposed additions verified — none introduce new Cat 4 sensitizer stack risk (no extra cinnamaldehyde / eugenol / methyl salicylate / oakmoss). Costus Olifac 10 % held at 25–30 µL ceiling per build (= 0.008–0.01 % in EDP) — well below 0.05 % Cat 4.

**Concentration note:** these additions bump each build by ~150–400 µL concentrate. To preserve the original 18–24 % EDP target, choose either:
- **(A) Slight concentration bump:** keep 30 mL fill, accept 23–26 % final → richer build, more longevity.
- **(B) Maintain concentration:** trim "molecular cocoon" materials (Iso E Super, Galaxolide, Ethylene Brassylate) by the equivalent µL added — keeps original concentration but reallocates volume from filler-musk to differentiator. Trade-off lines specify the recommended trim per build.

## Compounding addition protocol

For each formula, add the addition materials at the **end** of the existing compounding sequence, immediately before ethanol fill:

1. Build the v3 baseline per [Designer_Prestige_Eighteen_3K_to_15K_THB_2026-05-02.md](Designer_Prestige_Eighteen_3K_to_15K_THB_2026-05-02.md) compounding order.
2. Add the differentiation additions in order — base-tier additions (musks, ambers, woods) first, heart-tier (ionones, ketones) next, top-tier (citrus aldehydes, Apritone, Triplal) last.
3. Cap, invert 50×, macerate per the v3 schedule (most builds 6 weeks).

For Geosmin (Marine Profumo, Storm Wave): add as the very last drop before ethanol — it is so potent (ODT ~6 ppt) that mixing earlier risks distribution gradient. Stir with glass rod for 10 sec immediately after adding.

For Costus Olifac (5 builds): add early in the heart-tier additions to allow ethanol-DPG dispersion before adding more volatile materials on top.
