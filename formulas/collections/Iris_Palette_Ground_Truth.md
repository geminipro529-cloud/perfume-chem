# Iris Palette Ground Truth

Purpose: use the actual chemistry and CAS numbers below when building a realistic iris/orris accord, not the bottle names alone.

Date locked: 2026-04-08

## Core Identity Map

| Bottle Name | CAS | Actual Material | Practical Role |
|---|---|---|---|
| Alpha Irone | 79-69-6 / refined cis-alpha-irone grades vary | alpha-irone | True orris-root identity. Main realism anchor. |
| Orivone | 16587-71-6 | orris hexanone | Buttery-metallic fake orris body. |
| Methyl Ionone Pure | 127-51-5 | alpha-isomethyl ionone | Dense cosmetic/powder iris. Not generic methyl ionone. |
| AIMI | 127-51-5 | alpha-isomethyl ionone | Same chemistry territory as above. Check bottle/source before treating as separate. |

## Practical Interpretation

- Real orris truth: `Alpha Irone`
- Fake orris body: `Orivone`
- Fresh/dewy orris accent: `Irotyl`
- Dense powder/lipstick iris: `AIMI` and any bottle with CAS `127-51-5`
- Broad iris-violet body / halo: `Ultralia`
- Violet faceting: `Alpha Ionone`, `Beta Ionone`, `Allyl Ionone`
- Woody iris bridge: `Dihydro Beta Ionone`
- Premade scaffolds: `Orris F-TEC`, `I-IRIS F-TEC`
- Natural realism correction: `Carrot Seed EO`

## Rule For Realistic Iris/Orris Work

When aiming for realistic iris/orris:

1. Start from `Alpha Irone`.
2. Use `Orivone` for buttery-metallic body.
3. Use `Irotyl` and `Carrot Seed EO` for naturalistic carroty/root effects.
4. Treat `AIMI` / `127-51-5` materials as powder support, not as the main realism signal.
5. Treat `Ultralia` as halo/support, not as core orris identity.
6. Use `Orris F-TEC` and `I-IRIS F-TEC` as scaffolds, not proof of realism by themselves.

## Important Warning

If `Methyl Ionone Pure` and `AIMI` both carry CAS `127-51-5`, they are overlapping materials and should not be mentally counted as two clearly different chemistries.
