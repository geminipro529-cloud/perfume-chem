## Accord Breakdown

### Pear-Melon-Bergamot Opening (23% active)
**Pear Accord:** Hexyl Acetate (1.4% — green-waxy pear backbone) + Undecavertol (0.02% — juicy kiwi-pear, Givaudan-confirmed for pear accords) + Alpha Damascone (0.23% — ripe pear flesh, TGSC uses damascone at 22% of pear accord) + Benzyl Acetate (1.4% — fruity-floral pear blossom) + Ethyl Maltol (0.14% — jammy-sweet rounding) + Hexyl Salicylate (2.9% — green-floral fixative bridge). **Melon:** Melonal (0.43%) + Calone (0.01%) + Helional (0.86%). **Citrus:** Bergamot FCF Sicilian (5.1% — CONFIRMED) + Lemon FCF (0.57% trace). **Hedione** (7.1% — radiance scaffold). **Linalool** (4.3% — begins the freesia accord, bridges pear to heart).

### Freesia-Rose-Muguet Heart (20% active)
**Freesia Accord** (9.3%): Linalool (4.3%) + Beta Ionone (2.9%) + Alpha Isomethyl Ionone (2.3%) + PEA (2.3%) + Mayol (1.7%) + Hydroxycitronellal (1.7%). Follows the Olfactorian published freesia formula ratios (Linalool 50% + Beta Ionone 15% + Hedione 10% + Methyl Ionone 5% + PEA 5%). **Rose Accord** (3.7%): Geraniol (1.1%) + Citronellol (1.4%) + PEA (2.3% shared) + Damascone Beta (0.09%) + Rose Oxide (0.06%) + Geranium EO (1.1% confirmed). **White Floral Bridge:** ACA (1.4% — Hexyl Cinnamal substitute) + Aurantiol (0.57%) + Farnesol (0.43% confirmed).

### Rhubarb Accord — Embedded Trace (1.0% active)
Cyclamen Aldehyde (0.57% — rhubarb anchor, TGSC-documented rhubarb facet) + Galbanum EO (0.23% — bitter-green stalk) + AAG (0.06% — tart-green acidity) + Scentenal (0.002% — metallic-mineral edge) + Parmavert (0.17% — violet-leaf green bridge). Constructed across 4 axes: green-stalk (Galbanum + Parmavert), tart-acid (AAG), metallic-mineral (Scentenal), floral-rhubarb (Cyclamen Aldehyde).

### Patchouli-Musk-Amber Base — Nagel's "Petticoat" (34% active)
**Musk Chord (13.4%):** Galaxolide (5.7% — projection, Imixx GC-MS confirmed) + Habanolide (4.3% — skin-intimate) + Ethylene Brassylate (3.4% — depth axis). Nagel: "The musk note, which gives structure to the fragrance, is the petticoat — hidden, but without it the skirt would collapse." Total musk loading: 13.4% — below the 15–25% target for designer fruity-florals, but Jo Malone colognes are famously sheer. Boost to 18% by increasing Galaxolide to 600 µL if more "petticoat" is wanted. **Chypre Spine:** Patchouli EO (1.1% — CONFIRMED) + Iso E Super (7.1%) + Cedramber equivalent via Ambrox + Amberwood. **Amber:** Ambrox Super (1.1%) + Amberwood F (0.86%). **Fixatives:** Benzyl Benzoate (2.3% — CONFIRMED) + Sandalore (1.4% — CONFIRMED on Dossier label) + Heliotropal (0.23%).

## What This Formula Gets Right (vs. Easy Mistakes)

| Common Error | This Formula |
|---|---|
| **"Pear = pear ester"** — then frantically searching for it | Pear = Hexyl Acetate (backbone) + Undecavertol (juicy) + Alpha Damascone (ripe flesh) + Ethyl Maltol (sweet). Pear ester is only 0.1% in the TGSC patent formula. |
| **"Freesia = Miraldiacetate"** — an expensive captive | Freesia = Linalool 50% + Beta Ionone 15% + Hedione 10% + Ionones 5% + PEA 5%. The Olfactorian classical construction works. |
| **"Rhubarb = Styralyl Acetate"** — then giving up | Rhubarb = Cyclamen Aldehyde (TGSC-documented rhubarb facet) + Galbanum (stalk) + AAG (tart) + Scentenal (metallic). 4-axis construction. |
| **"Hexyl Cinnamal is irreplaceable"** | ACA — same family, 1:1 replacement, many perfumers prefer it. |
| **"Lilial is banned so the formula is broken"** | Mayol — transparent muguet-lily, IFRA-safe, cleaner character. |
| **"The musk is just background"** | Nagel's own words: "without it the skirt would collapse." 3-material musk chord at 13.4% — Galaxolide (projection) + Habanolide (intimacy) + EB (depth). |

## Dosing & Mixing Notes

1. **Order of addition:** Hedione → Iso E Super → Hexyl Acetate → Bergamot → Galaxolide → Linalool → Habanolide → EB → Sandalore → Benzyl Benzoate → Hexyl Salicylate → Beta Ionone → AI Ionone → PEA → Benzyl Acetate → Alpha Damascone → Mayol → ACA → Citronellol → Hydroxycitronellal → Ambrox Super → Patchouli → Geraniol → Ethyl Maltol → Amberwood F → Geranium EO → Melonal → Helional → Calone → Undecavertol → Aurantiol → Damascone Beta → Cyclamen Aldehyde → Rose Oxide → AAG → Lemon FCF → Farnesol → Heliotropal → Parmavert → Galbanum → Scentenal. Ethanol last.
2. **Hexyl Acetate at 10% → 500 µL** is the largest diluted line. Ensure the 10% solution is well-mixed — Hexyl Acetate is a thin, volatile ester.
3. **Undecavertol 1% → 80 µL:** Extremely powerful at 1% dilution. ODT is very low — increasing this will make the entire formula read as "violet leaf." Leave at 80 µL.
4. **Scentenal 1% → 8 µL:** The most powerful material in the formula. Even 12 µL would push the rhubarb accord from "trace metallic" to "harsh-chemical." Do NOT increase.
5. **ACA at 50 µL:** Same dose as the original Hexyl Cinnamal. If the jasmine character reads too prominent, reduce to 35 µL. If the white floral bridge needs more body, increase to 70 µL.
6. **Maceration:** 2 weeks minimum. The pear accord (Hexyl Acetate + Undecavertol + Damascone) needs time to integrate — the first 3–5 days the hexyl acetate will read sharply. The Galbanum + Scentenal rhubarb accord also needs time to soften.
7. **The musk "petticoat" effect** won't be fully apparent until week 1 — Habanolide + EB need time to bloom into the clean-skin warmth that Nagel describes. Testing before 1 week: the fragrance will read as "pear-freesia" with a thin base.
