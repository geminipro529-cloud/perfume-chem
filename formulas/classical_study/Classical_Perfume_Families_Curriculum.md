# Classical Perfume Families Study Set

**Purpose:** Learn the historically central architecture of each classical family through current-stock, modern-safe 30 mL study formulas.  
**Constraint set:** `Petitgrain EO` is depleted, `Neroli EO` is absent, true oakmoss is absent, true labdanum is absent, and vintage animalics are absent. Each formula records those gaps instead of hiding them.

## How To Use The Set

1. Smell within clusters first: cologne and fougère together, floral families together, chypres together, ambers together.
2. Compare each study's `Historical gap` against its formula to see how the stock-safe substitutes preserve the structure.
3. Run the pipeline with the explicit `Family archetype` to confirm the formula still reads as the historical family rather than a modern flanker.
4. When new materials arrive, upgrade along the `Historical upgrade path` instead of rewriting the entire structure.
