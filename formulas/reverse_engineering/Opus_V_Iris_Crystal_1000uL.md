## Intent

This is not the full dark `Opus V` signature.

It is the **crystallized iris center**:
- buttery
- metallic-cool
- waxy
- polished
- only lightly rooted

What was intentionally reduced or removed:
- `Ambrox Super`
- `Vetival`
- `Heliotropin Fleuressence`
- `Coumarin (20%)`
- heavy powder-warm ballast

That makes this version much easier to place inside:
- woody
- musk
- ambroxan
- floral
- transparent modern compositions

## Why This Works

### 1. The Opus V identity stays in the center

The main `Opus V` iris code is still here:
- `Alpha Irone`
- `Orivone`
- `Orris F-TEC`
- `Methyl Ionone Pure`
- the ionone-violet field

So the accord still reads as:
- buttery orris
- metallic-cool concrete
- refined iris rather than generic violet

### 2. The ballast is no longer steering the whole accord

The old dark push came partly from:
- `Ambrox Super`
- `Vetival`
- `Heliotropin`
- `Coumarin`

Those are not in the crystal version. The result is less:
- dark
- dusty
- warm-powdered
- woody underneath

And more:
- legible
- adaptable
- easy to frame with other families

### 3. The accord now breathes

`Hedione` is high enough to keep the module from collapsing into root paste.

That matters if this has to sit inside:
- floral-woods
- musks
- ambroxan structures
- clean modern perfumes

## Mixing Order

1. Add the heavy iris body:
   `Orivone`, `Methyl Ionone Pure`, `Orris F-TEC`, `I-IRIS F-TEC`, `Allyl Ionone (Ketone V)`, `Dihydro Beta Ionone`, `Irotyl`, `Ultralia`.
2. Add the irone-violet section:
   `Alpha Ionone`, `Beta Ionone`, `Alpha Irone (10%)`.
3. Add `Bacdanol`.
4. Add `Hedione`.
5. Add `Carrot Seed EO`.
6. Add `Rose Oxide (1%)` last.
7. Rest `7 days` minimum.
8. Best read: `14 days`.

---

## How To Use It

- `Floral / musky / clean woody`: `8-15%` of concentrate
- `Transparent ambroxan / mineral woody`: `6-12%`
- `Dark woods / amber / incense`: `8-14%` plus [Opus_V_Iris_Shadow_Booster_1000uL.md](d:\chatbots\perfume-chem\Opus_V_Iris_Shadow_Booster_1000uL.md) at `2-6%`
- `Sport-adjacent`: `4-9%`, but it still needs a bright external shell

Not ideal for:
- pure aquatic
- ultra-bright cologne
- very ozonic structures

---

## Adjustment Knobs

If it is too buttery:
- reduce `Orivone` by `10 uL`
- raise `I-IRIS F-TEC` by `10 uL`

If it is too abstract and not rooty enough:
- raise `Orris F-TEC` by `10 uL`
- raise `Carrot Seed EO` by `2-3 uL`

If it needs more cold concrete edge:
- raise `Rose Oxide (1%)` from `10 uL` to `12-15 uL`

If it feels too soft:
- reduce `Bacdanol` by `5 uL`
- raise `Dihydro Beta Ionone` by `5 uL`
