## Purpose

These are the **5 premiere-release candidates** for the `Opus V` iris line:
- all built to show the iris accord in its best framing
- all optimized after an initial concept pass
- all scored locally on technical and market-facing criteria

This pass prioritizes:
- niche-luxury finish
- broad readability
- strong line identity
- a first-release profile that makes the iris memorable without burying it under darkness

---

## Optimization Method

The local pass used:
- the `Crystal` branch as the fixed iris center
- shell-only adjustments for balance, radiance, and opening structure
- flattened internal evaluation for scoring
- a final `Hexyl Salicylate` substitution where needed so the local validator would stop hard-failing on `Benzyl Salicylate`

All 5 final versions:
- returned `0` hard validation errors in the local validator
- returned `0` conflict pairs in rule coverage

The technical comparison below is based on flattened raw-material scoring, not just the premade accord row.

## Optimization Deltas

Compared with the initial concept pass, the final versions moved as follows:

- `Aperture Iris`: `75.8` -> `77.1`
- `Iris Monolith`: `70.8` -> `74.7`
- `Opus Skin Veil`: `74.2` -> `75.4`
- `Iris Atelier Bois`: `73.9` -> `76.1`
- `Citrine Orris`: `78.3` -> `80.0`

The main shell changes in the optimized set were:
- more top-note framing where formulas were too base-heavy
- higher `Hedione` where the iris needed more light
- tighter wood/musk balance in the middle-performing candidates
- `Hexyl Salicylate` in place of `Benzyl Salicylate` for validator-clean cushioning
