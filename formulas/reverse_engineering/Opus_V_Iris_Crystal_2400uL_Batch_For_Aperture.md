## Mixing Order

1. Start with the heavy iris body:
   `Orivone`, `Methyl Ionone Pure`, `Orris F-TEC`, `I-IRIS F-TEC`.
2. Add the ionone/irone field:
   `Alpha Irone`, `Alpha Ionone`, `Beta Ionone`, `Allyl Ionone (Ketone V)`, `Dihydro Beta Ionone`.
3. Add the supporting iris detail:
   `Irotyl`, `Ultralia`, `Carrot Seed EO`.
4. Add `Bacdanol`.
5. Add `Hedione`.
6. Add `Rose Oxide (1%)` last.
7. Rest at least `7` days before use.
