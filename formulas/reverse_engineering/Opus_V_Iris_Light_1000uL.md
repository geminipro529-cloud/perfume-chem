## Why This Works

### 1. The heavy floor is mostly gone

No:
- `Bacdanol`
- `Ambrox Super`
- `Vetival`
- `Heliotropin`
- `Coumarin`

That keeps the accord from immediately reading:
- dusty
- dark
- root-powdered
- woody underneath

### 2. The airy iris materials are now doing more work

Compared with the richer versions, this branch leans harder on:
- `I-IRIS F-TEC`
- `Dihydro Beta Ionone`
- `Ultralia`
- `Hedione`

So the result is more:
- transparent
- polished
- bright-edged
- easier to modernize

### 3. The Opus V fingerprint is still there

Even here, the accord still keeps:
- `Alpha Irone`
- a trace of `Orivone`
- `Orris F-TEC`
- the metallic `Rose Oxide` chill

So it does not become generic ionone floral powder.

## Mixing Order

1. Add the iris body materials:
   `Orivone`, `Methyl Ionone Pure`, `Orris F-TEC`, `I-IRIS F-TEC`, `Allyl Ionone (Ketone V)`, `Dihydro Beta Ionone`, `Irotyl`, `Ultralia`.
2. Add the irone-violet section:
   `Alpha Ionone`, `Beta Ionone`, `Alpha Irone (10%)`.
3. Add `Hedione`.
4. Add `Carrot Seed EO`.
5. Add `Rose Oxide (1%)` last.
6. Rest `5-7 days` minimum.
7. Best read: `10-14 days`.

---

## How To Use It

- `Clean musk / office iris`: `6-12%` of concentrate
- `Transparent woody / mineral`: `5-10%`
- `Bright floral iris`: `6-14%`
- `Sport-adjacent`: `4-8%`
- `Ozonic / watery`: use cautiously at `3-6%`

This is still not a true aquatic or gym-fresh module. It is just the lightest `Opus V` branch in the system.

---

## Adjustment Knobs

If it is too light and loses character:
- raise `Orivone` by `5-10 uL`
- raise `Orris F-TEC` by `10 uL`

If it still feels too waxy:
- reduce `Orivone` by `5 uL`
- raise `Hedione` by `10 uL`

If it lacks dry persistence:
- raise `Dihydro Beta Ionone` by `10 uL`
- reduce `Methyl Ionone Pure` by `10 uL`

If it needs a cleaner colder edge:
- raise `Ultralia` by `5 uL`
- raise `Rose Oxide (1%)` by `2-3 uL`
