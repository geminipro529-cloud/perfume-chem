# Base Type Compatibility for Material Safety

## Overview
Not all materials work in all bases. Transparent bases expose objectionable facets (fecal, animalic, dirty) that heavy bases mask. This document classifies bases and defines safe material usage.

---

## Base Type Classification

### Type 1: Clean/Transparent
**Character:** Airy, fresh, minimal fixatives (<5% heavy materials)

**Examples:**
- BR540 (saffron + ambroxan + cedar + jasmine)
- Acqua di Gio (citrus + marine + woods)
- Light Blue (citrus + floral + apple)
- CK One (citrus + green + musk)

**Incompatible Materials:**
- ❌ Animalics (skatole, indole, oud, castoreum, civet)
- ❌ Heavy resins >2% (labdanum, benzoin, myrrh)
- ❌ Fecal-adjacent (cumin, costus, birch tar)
- ❌ Dirty notes (oakmoss absolute, vetiver absolute >1%)

**Why:** Nothing to buffer objectionable facets → materials smell exactly as they are (fecal = fecal).

**Safe Additions:**
- ✅ Clean musks (galaxolide, habanolide, exaltolide)
- ✅ Light florals (hedione, linalool, geraniol)
- ✅ Transparent woods (iso E super, ambroxan, cetalox)

---

### Type 2: Heavy Oriental/Resinous
**Character:** Sweet, opulent, >10% fixatives (vanilla/benzoin/labdanum/tonka)

**Examples:**
- Dior Homme Parfum (iris + vanilla + leather)
- Tom Ford Tobacco Vanille (vanilla + tobacco + tonka)
- Guerlain Spiritueuse Double Vanille (vanilla + benzoin + rose)

**Compatible Materials:**
- ✅ Animalics at trace (0.01-0.05% final) for depth
- ✅ Heavy resins (up to 20% combined)
- ✅ Dark spices (cumin 0.1%, cinnamon, clove)
- ✅ Oud accords (0.5-3%)

**Why:** Heavy sweet/resinous base masks fecal/dirty notes, creates luxury context.

**Dosage Rules:**
- Animalics: 0.01-0.05% max (1-3 drops per 50 mL)
- Oud: 0.5-2% max
- Cumin: 0.05-0.2% max

---

### Type 3: Chypre/Mossy
**Character:** Bergamot + floral + oakmoss/patchouli base

**Examples:**
- Miss Dior (original)
- Mitsouko
- Aromatics Elixir

**Compatible Materials:**
- ✅ Oakmoss up to 5% (traditional)
- ✅ Patchouli 5-15%
- ✅ Animalics 0.05-0.1% (civet, castoreum)
- ✅ Leather notes (birch tar, castoreum)

**Why:** Mossy/earthy base has similar dirty facets → animalics blend in rather than stand out.

---

### Type 4: Leather/Animalic
**Character:** Birch tar, castoreum, oud-dominant

**Examples:**
- Cuir de Russie
- Tuscan Leather (Tom Ford)
- Oud Wood

**Compatible Materials:**
- ✅ Skatole/indole 0.1-0.5% (already dirty base)
- ✅ Cumin up to 0.5%
- ✅ Oud 5-20%
- ✅ Civet, castoreum, hyraceum

**Why:** Base is ALREADY animalic/dirty → adding more doesn't make it worse, just richer.

---

### Type 5: Fougère/Aromatic
**Character:** Lavender + coumarin + oakmoss

**Examples:**
- Dior Sauvage
- Bleu de Chanel
- Joop! Homme

**Moderately Compatible:**
- ⚠️ Animalics 0.01-0.03% (subtle depth only)
- ✅ Cumin 0.05-0.1% (aromatic lift)
- ✅ Oakmoss/patchouli 1-5%

**Caution:** More transparent than chypres → use animalics sparingly.

## Validation Rules

### Pre-Dosage Check
Before recommending any animalic/objectionable material:

1. **Classify base type** (from formula composition)
2. **Check compatibility matrix** (above)
3. **If incompatible → DO NOT RECOMMEND**
4. **If compatible → Check ODT → Calculate OV → Verify dose**

### Compatibility Matrix

| Material Class | Clean | Heavy Oriental | Chypre | Leather | Fougère |
|----------------|-------|----------------|--------|---------|---------|
| Skatole/Indole | ❌ | ✅ (0.01-0.05%) | ✅ (0.05-0.1%) | ✅ (0.1-0.5%) | ⚠️ (0.01-0.03%) |
| Oud accords | ❌ | ✅ (0.5-2%) | ⚠️ (0.5-1%) | ✅ (5-20%) | ❌ |
| Cumin | ❌ | ⚠️ (0.05-0.2%) | ✅ (0.1-0.3%) | ✅ (0.2-0.5%) | ⚠️ (0.05-0.1%) |
| Oakmoss abs | ❌ | ⚠️ (<1%) | ✅ (2-5%) | ✅ (1-3%) | ✅ (1-5%) |
| Civet/Castoreum | ❌ | ✅ (0.02-0.1%) | ✅ (0.1-0.3%) | ✅ (0.3-1%) | ⚠️ (0.02-0.05%) |

**Legend:**
- ✅ = Safe (typical usage range shown)
- ⚠️ = Use with caution (narrow safe range)
- ❌ = DO NOT USE (incompatible, will smell wrong)

## Known Failures (Learn from These)

### Failure 1: Skatole in BR540
- **Base:** BR540 (clean/transparent)
- **Dose:** 0.2 mL skatole 1% in 50-100 mL base
- **Result:** Fecal disaster
- **Why:** Base incompatibility (Type 1 base + animalic = always fails)
- **OV:** ~20,000-40,000 (extreme overdose)
- **Lesson:** Never use animalics in clean bases, regardless of dose

### Failure 2: Oud Overload in Vanilla Blend
- **Base:** Heavy oriental (vanilla + benzoin)
- **Dose:** 0.5 mL oud in 50 mL
- **Result:** Still too fecal (but better than in BR540)
- **Why:** Dose too high even for compatible base
- **OV:** ~5,000 (still overpowering)
- **Lesson:** Even in compatible bases, animalics must be trace-level

### Failure 3: Benzoin Waste in Large Batch
- **Base:** BR540 (100 mL batch)
- **Dose:** 10 mL benzoin siam resinoid
- **Cost:** $7.00 wasted
- **Result:** Functionally identical to 5 mL benzoin + cheap substitutes
- **Why:** Expensive material used in large untested batch
- **Better approach:** Use 5 mL vanillin 10% + labdanum 10% + amber accord (saves $3.50)
- **Lesson:** Test in small batches (10-20 mL) before scaling expensive materials

### Failure 4: Hedione + Benzyl Benzoate Overuse
- **Materials:** Hedione (neat) + Benzyl Benzoate (co-solvent)
- **Common mistake:** "Add 25 drops hedione + 2 mL benzyl benzoate" for every enhancement
- **Problem:** Both are **expensive** and often unnecessary
  - Hedione: $0.80/mL (moderate cost)
  - Benzyl Benzoate: $0.20/g (adds up in large batches)
- **Why it happens:** Generic "radiance booster" recommendation without checking if base needs it
- **When NOT to use:**
  - Base already has >5% jasmine materials
  - Base is floral-heavy (hedione will be redundant)
  - Formula is cloudy due to OTHER issues (benzyl benzoate won't fix polarity mismatch)
- **Better approach:**
  - Check if base NEEDS radiance (is it flat/linear?)
  - Use hedione only 0.5-2% (10-40 drops per 50 mL), not 25+ drops
  - Use benzyl benzoate ONLY if precipitation/cloudiness occurs (1-2 mL max)
- **Lesson:** Don't add "boosters" by default—diagnose the problem first

## Safe Usage Guidelines

### For Animalics (Skatole, Indole, Oud)

1. **Base must be Type 2, 3, or 4**
2. **Pre-dilute to 1% or 0.1%** in ethanol for dosing control
3. **Add by drops** (1 drop ≈ 0.02-0.03 mL)
4. **Start with 1-2 drops per 50 mL** base
5. **Test 24 hours later** (animalics bloom over time)
6. **If fecal → dilute or discard** (cannot be rescued)

### For Clean Bases (Type 1)

**DO NOT ADD:**
- Skatole
- Indole (except at 0.001% for jasmine authenticity)
- Oud accords
- Cumin
- Castoreum
- Civet

**Safe alternatives for depth:**
- Exaltolide (clean musk)
- Iso E Super (transparent woody)
- Ambroxan (clean amber)
- Cetalox (transparent ambergris)
