# Repo Gap-Fill Matrix — MITH Bangkok, Vibeslab, and Shared Market Gaps

**Date:** 2026-05-25  
**Purpose:** map competitor gaps and Thai market gaps to whether the repo already contains a product that can fill them.  
**Important distinction:** some gaps are **product gaps** and some are **structural business-model gaps**. A formula can fill the first type. It cannot by itself fill the second.

---

## 1. How to read this

- **Gap type**
  - `product` = a launchable scent/product can directly attack it
  - `structural` = requires channel, B2B, body-care, sampling, or portfolio architecture
- **Gap-fill score**
  - `90-100` = repo already has a very strong fit
  - `80-89` = strong fit with minor remediation
  - `70-79` = partial fit, needs clearer positioning
  - `<70` = repo does not really fill it yet

## 6. Gaps the repo does **not** currently fill well

These are the important gaps where the repo does **not** yet have a fully convincing product answer:

- **B2B scent-branding service moat**
  - no formula can replace this by itself
- **Body-care ecosystem products**
  - scent cores exist, but packaged product extensions are not already built out
- **Dedicated discovery / experiment kit architecture**
  - many scents could populate a kit, but the kit is not already defined as a commercial object
- **Bridge-size product strategy at 1,500-2,500 THB**
  - scent candidates exist, but the pricing/pack architecture is not defined

---

## 7. Bottom line

Yes, the repo already contains multiple products that fill real competitor and market gaps.

The clearest ones are:

- **Bangkok Compass**
- **Makrut Tropic**
- **Mango Mademoiselle**
- **Thai Oud**
- **Cobalt Cedar Air**
- **Royal Tonka**

But the repo does **not** yet fill the most structural gaps:

- MITH's lack of B2B moat
- Vibeslab's body-care and bridge-size architecture
- the shared discovery-set and product-system opportunity

So the strongest reading is:

- the repo already has several **bottle-level winners**
- it does **not** yet have every **business-model-level answer**
