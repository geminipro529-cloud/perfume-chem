# Dior RC1 Hardened Recipe Package

Open **`index.html`** for the searchable library.

## Root files

- `Dior_RC1_Hardened_Recipe_Master.xlsx` · master Excel workbook
- `Dior_RC1_Hardening_Report.md` · complete hardening report
- `Dior_RC1_Monte_Carlo_Summary.csv` · Monte Carlo summary
- `Dior_RC1_Cross_Flanker_Differentiation.csv` · cross-flanker matrix
- `Dior_RC1_Final_Gate.csv` · final RC1 gate
- `Dior_RC1_Master_Recipes.csv` · every recipe row in one CSV
- `Dior_RC1_Hardening_Model.json` · machine-readable RC1 model

## Per perfume

Each perfume folder contains:

1. final RC1 recipe CSV;
2. final RC1 recipe Markdown;
3. browser bench card;
4. Monte Carlo report;
5. sensitivity and ablation map;
6. high-dose and trace audit;
7. V1-to-RC1 changelog;
8. formula hash.

## Boundary

All formulas are robust computational release candidates, not authenticated Dior production formulas or measured physical matches.
