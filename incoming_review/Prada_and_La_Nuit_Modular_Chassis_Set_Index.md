# Prada L’Homme and YSL La Nuit Modular Chassis Set

## Files in this set

1. **Prada spice-open chassis**
   - fixed chassis: 4,412 µL
   - replaceable spice socket: 88 µL
   - retains the inventory-fit iris/violet and clean-soap identity

2. **Prada iris/violet-open floral chassis**
   - fixed chassis: 3,992 µL
   - replaceable floral identity socket: 508 µL
   - retains soap/muguet, neroli, geranium, clean musk, woods, amber, and the source spice direction

3. **YSL La Nuit spice-open chassis**
   - fixed chassis: 4,412 µL
   - replaceable spice socket: 88 µL
   - retains the dark woody, musk, violet, aromatic-fougère, and tonka framework

## Which Prada chassis to use

- Use the **spice-open** file when the flower identity should remain Prada-like and only the spice direction changes.
- Use the **iris/violet-open** file when the dominant flower should change.
- They are alternative partitions of one 4,500 µL target. Do not stack the 88 µL spice socket and 508 µL floral socket without constructing and validating a new dual-socket partition.

## Parent target versus build

The uploaded source formulas remain theoretical target records. These new documents are inventory-mapped build formulas. Missing inventory changes the build, not the target.

## Bench rule

Every custom module replaces its complete parent module or control at equal raw volume. Never add a module on top.
